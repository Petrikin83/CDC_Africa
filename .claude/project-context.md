# CDC Africa Project Context

## Project Overview

**Project Name:** CDC Africa Landing / Gateway Website

**Type:** Single-page B2B/B2G landing website (NOT a full corporate site)

**Purpose:** Regional gateway and funnel page to route users to the global CDC platform

**Repository:** https://github.com/Petrikin83/CDC_Africa

---

## Core Positioning

```
CDC Africa = Local presence in Africa + Access to CDC global engineering
```

CDC Africa is the **African regional hub / entry point** to CDC's global ropeway engineering platform.

### Main Brand Slogan
```
Infrastructure That Moves Economies.
```

---

## What This Site Is NOT

❌ Full corporate website with complete portfolio
❌ Product showcase with multiple product pages
❌ Tourist-focused travel site
❌ Startup-style casual branding
❌ Independent company (it's a regional hub)

---

## What This Site MUST DO

1. **Show CDC presence in Africa** through CDC Africa
2. **Explain project types** that CDC Africa can route
3. **Make users understand** this is a local entry point to global expertise
4. **Route interested users to cdc.company** through clear CTAs

### Primary Goal
> **Route users to cdc.company without overloading the page with content**

---

## Target Audience

**B2B / B2G decision makers:**

- Governments & city authorities
- PPP units & infrastructure authorities
- Developers & investors
- DFIs (Development Finance Institutions)
- Mining operators
- Tourism destination developers
- Urban planners
- Institutional partners

### Tone of Voice
```
Serious, engineering-focused, investment-oriented, international
```

**NOT:** Startup-like, tourist-focused, overly promotional, decorative

---

## Technology Stack

- **HTML/CSS/JS** — Static, GitHub Pages compatible
- **Tailwind CSS** — CDN for prototyping
- **AOS** — Scroll animations library
- **Responsive** — Mobile-first approach

---

## Key Markets / Project Types

CDC Africa should position itself for:

1. **Urban Mobility** — City cableways, congestion relief
2. **Tourism** — Mountain/park access (Kilimanjaro-type)
3. **Remote Connectivity** — Cable bridges, island access (Madagascar-type)
4. **Mining & Extractive** — Heavy-load industrial logistics
