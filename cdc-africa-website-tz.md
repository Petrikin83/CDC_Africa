# ТЗ: CDC Africa Landing / Gateway Website

## 1. Общая суть проекта

Нужно сделать профессиональный B2B / B2G landing page для **CDC Africa**.

Это не полноценный отдельный корпоративный сайт. Это **региональная посадочная страница-воронка**, задача которой:

1. показать, что CDC присутствует в Африке через CDC Africa;
2. объяснить, какие типы проектов CDC Africa может маршрутизировать;
3. дать пользователю понять, что CDC Africa — локальная точка входа к глобальной инженерной экспертизе CDC;
4. направить заинтересованных пользователей на головной сайт **cdc.company**.

Главная цель сайта:

> Увести пользователя на **cdc.company** через понятные CTA, не перегружая страницу лишним контентом.

CDC Africa должен восприниматься как:

> African regional hub / entry point to CDC global ropeway engineering.

Не нужно создавать ощущение отдельной независимой компании с полным портфолио. Нужно показать:

> CDC Africa = local presence in Africa + access to CDC global engineering.

---

## 2. Главная маркетинговая идея

Сайт должен говорить не просто про “канатные дороги”, а про:

- инфраструктуру;
- экономический рост;
- PPP;
- города;
- туризм;
- удалённый доступ;
- cable bridges;
- mining / extractive sector.

Основной брендовый слоган:

```text
Infrastructure That Moves Economies.
```

Почему именно он:

- взят из government / PPP версии;
- подходит для городов, туризма, remote access, cable bridges и mining;
- звучит серьёзно для governments / investors / PPP;
- не ограничивает продукт только перевозкой пассажиров;
- хорошо работает как верхний уровень перед переходом на cdc.company.

Подзаголовок в hero:

```text
Ropeway infrastructure for African cities, tourism destinations, cable bridges, remote regions and mining operations — powered by CDC global engineering.
```

Hero не должен быть перегружен.

Не добавлять в hero лишние строки типа:

```text
Kigali, Rwanda • Regional Infrastructure Hub
CDC Africa brings global CDC engineering...
We are in Africa. One partner. Full responsibility.
```

Эти смыслы лучше раскрывать ниже: в trust strip и About.

---

## 3. Целевая аудитория

Сайт должен быть рассчитан на B2B / B2G аудиторию:

- governments;
- city authorities;
- PPP units;
- infrastructure authorities;
- developers;
- investors;
- DFIs / development banks;
- mining operators;
- tourism destination developers;
- urban planners;
- institutional partners.

Тональность:

> Serious, engineering, investment-oriented, international.

Не делать сайт слишком:

- стартапным;
- туристическим;
- рекламно-кричащим;
- декоративным без инженерного смысла.

---

## 4. Ключевая цель UX

Путь пользователя должен быть простым:

```text
Hero → понять ценность → увидеть типы проектов → выбрать свой use case → перейти на cdc.company
```

Сайт не должен пытаться закрыть всю продажу на себе. Он должен:

- объяснить направление;
- создать доверие;
- показать сценарии применения;
- отправить пользователя на глобальный сайт.

Основной CTA:

```text
Explore CDC Global Capabilities
```

Вторичный CTA:

```text
View African Use Cases
```

Для карточек use cases CTA должны быть контекстными:

```text
Explore urban capabilities →
Explore tourism capabilities →
Explore remote access capabilities →
Explore mining capabilities →
```

## 7. Hero Background

Hero должен использовать основное фото:

```text
./hero-bg.png
```

Фон должен быть видимым, не слишком затемнённым. После переноса текста влево нужно дать правой части изображения больше воздуха.

Логика overlay:

```text
left side: darker for readability
right side: lighter so engineering structure is visible
bottom: darker for transition
```

Desktop CSS example:

```css
.hero-parallax {
    background-image:
        radial-gradient(circle at 74% 36%, rgba(255,117,31,0.08), transparent 34%),
        linear-gradient(90deg, rgba(46,46,46,0.88) 0%, rgba(46,46,46,0.76) 34%, rgba(46,46,46,0.34) 64%, rgba(46,46,46,0.48) 100%),
        linear-gradient(to bottom, rgba(46,46,46,0.28) 0%, rgba(46,46,46,0.54) 58%, rgba(46,46,46,0.90) 100%),
        url('./hero-bg.png');
    background-attachment: fixed;
    background-size: cover;
    background-position: center right;
}
```

Mobile CSS example:

```css
@media (max-width: 768px) {
    .hero-parallax {
        background-attachment: scroll;
        background-position: center;
        background-image:
            radial-gradient(circle at 50% 28%, rgba(255,117,31,0.10), transparent 34%),
            linear-gradient(to bottom, rgba(46,46,46,0.66), rgba(46,46,46,0.94)),
            url('./hero-bg.png');
```

## 9. Технические требования

Сайт должен быть:

```text
single-page landing
static HTML/CSS/JS
GitHub Pages compatible
responsive
fast enough for mobile
```

Можно использовать Tailwind CDN для прототипа, но для production лучше собрать CSS локально.

Обязательно:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

External links:

```html
target="_blank"
rel="noopener noreferrer"
```

CTA links to cdc.company должны иметь UTM:

```text
utm_source=cdc_africa
utm_medium=landing
utm_campaign=africa_gateway
utm_content=...
```

Примеры `utm_content`:

```text
hero_primary_cta
nav_cta
usecase_urban
usecase_tourism
usecase_remote
usecase_mining
mining_cta
technology_cta
ppp_cta
footer_primary_cta
mobile_sticky_cta
```

## 10. JS / UX behavior

---

### Compact header on scroll

После скролла header должен становиться компактнее:

```text

```

---

### Active nav state

Подсвечивать текущую секцию меню.

Важно:

```text
На hero никакой пункт меню не должен быть активным.
```

---

### Mobile menu

Нужно:

- кнопка `Menu`;
- открытие / закрытие меню;
- закрытие после клика по пункту.

---

### Mobile sticky CTA

На мобильных можно показывать sticky CTA после прокрутки части hero:

```text
Explore CDC Global Capabilities
```

Он не должен мешать меню и footer.

---

### AOS animation fallback

Если используется AOS, нужен fallback:

```js
if (window.AOS) {
    AOS.init(...)
} else {
    document.querySelectorAll('[data-aos]').forEach((element) => {
        element.style.opacity = '1';
        element.style.transform = 'none';
    });
}
```

И noscript fallback:

```html
<noscript>
    <style>
        [data-aos] {
            opacity: 1 !important;
            transform: none !important;
        }
    </style>
</noscript>
```
